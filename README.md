# Дистилляция и ускорение моделей — ДЗ № 1

Анализ **BERT-base для классификации тональности английских кинорецензий** в сценарии онлайн-инференса на CPU Intel Xeon Gold 6230.

Основной результат — [аналитический отчёт](REPORT.md). Он покрывает все семь пунктов задания: контекст применения, платформу, архитектуру, затраты и bottlenecks, системные ограничения, способы ускорения и инженерные компромиссы. Включены схема модели, ссылки на первичные источники и план проверки гипотез.

## Повторение расчётов

```bash
python3 scripts/analyze_bert.py
```

Нужен только Python 3.10+ со стандартной библиотекой. Команду можно выполнять из любой директории; файлы результатов сохраняются относительно расположения скрипта. Она не скачивает веса, не обучает модель и не измеряет latency. Аппаратная платформа и нагрузка в отчёте заданы как проектный сценарий.
